# Weather app

A minimal weather app built with Flutter. It shows the current conditions for your location and a 10-day forecast, with search for any city worldwide.

Weather data by [Open-Meteo](https://open-meteo.com) (free, no API key required).

## Features

- Current weather for your location (temperature, "feels like", conditions)
- 10-day daily forecast
- City search with worldwide geocoding
- Saved locations history
- Pull to refresh
- Light and dark themes, with the choice persisted
- English and Russian localization, with the choice persisted
- Weather icons mapped from WMO weather codes
